# Loom 隐私说明

本应用把项目目标、任务标题、固定日程、工作时段和进度数据发送到服务端，服务端把它们转发给 MiniMax 用于规划与排程。客户端不直接保存任何模型密钥。

## 接收方

- **MiniMax 模型提供方**（`api.minimax.chat`）：接收完整项目快照与对话上下文。提供方在其服务端保留推理内容；按 MiniMax 隐私条款处理，不在应用控制范围内。
- **Loom 服务端**：本项目部署的服务（独立于应用包，不随客户端发布）。运行时默认不长期保存项目内容；仅记录请求编号、耗时、用量与错误类型。

## 不上传到服务端

- 模型密钥：仅服务端持有，客户端包内无密钥、令牌或登录表单。
- 用户偏好设置可包含敏感措辞；如不希望共享，请勿在 preferences 字段填入。
- 本地 A/B 快照（`snap-a.json` / `snap-b.json`）仅在设备本地的应用 jail 中存在。

## 离线

- 离线时可继续查看本地计划与记录进度。
- 涉及远程模型的规划在离线时显示"暂不可用"，不偷跑。

## 权限检查与硬约束

- 客户端与服务器独立实现 C1–C7 硬约束；服务器误判通过时客户端仍可能拒绝。
- 即使用户文本含注入指令，模型无法绕过程序层面的权限判定与硬约束。
- 进度以任务的"剩余工时"为唯一依据；时间块完成状态不自动换算成任务进度，避免伪造完成。

## 安全说明

- 所有 `https://` 主机必须在 `bundle/manifest.json` 的 `network.hosts` 中声明。
- 包内无密钥、无登录表单、无 password / one-time-code 字段。
- 涉及截止日风险的方案需要用户明确批准，批准仅对当前方案有效，不永久扩大授权。
