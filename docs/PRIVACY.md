# Loom 初赛演示隐私说明

客户端在设备的应用目录保存项目目标、任务、剩余工时、固定日程、里程碑、日历、方案、核验回执和暂停状态。离线时可以查看日历并更新项目资料。

用户发起任务建议或规划时，客户端通过 HTTPS 把完整项目、当前时间和必要对话发送到 Loom 服务端。服务端把这些内容与工具调用历史发送到 MiniMax。实际规划资料按照模型提供方的服务规则处理。

服务端将暂停对话保存在 SQLite 中，用于恢复同一轮规划；暂停凭据有效期为 24 小时，过期记录在产生新的暂停状态时清理。执行中的规划结果保留在服务内存中，完成结果在一小时后且有新的请求时清理。使用记录包含日期、额度类别、提供方报告的 token 数量、估算费用和未确认用量的预留金额。HTTP 日志记录访问地址、路由和状态，错误日志说明错误类型。

当前开发 HTTPS 连接经过 Cloudflare 临时隧道转发到本机服务。隧道终止后，该开发连接失效。

MiniMax 密钥与可选评审凭据仅由服务端环境提供，应用包不保存模型密钥，也不提供登录或密码输入。单次恢复凭据保存在本地暂停状态中，只用于恢复对应规划。

需要清理数据时，关闭客户端后删除对应的应用数据目录；关闭服务后删除 `LOOM_USAGE_DB` 指定的 SQLite 文件。初赛范围为单用户和单设备，项目使用应用内日历。
