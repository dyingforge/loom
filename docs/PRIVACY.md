# Loom 隐私说明

Loom 是零服务化的自包含客户端，不维护任何自有服务端，也不保存模型密钥、登录或密码。

## 本地数据

客户端在设备的应用目录交替写入 `state-a.json` 与 `state-b.json` 两份完整 JSON 快照，保存目标、截止日期、任务、日历、候选计划、正式计划、修改建议、草稿、核验回执和演示标记。每次保存后回读比较，启动时恢复序号最大的完整记录。时间固定为东八区（UTC+8）。离线时可以查看已经保存的日历。

需要清理数据时，关闭客户端后删除对应的应用数据目录，其中的 `state-a.json` 与 `state-b.json` 即全部本地业务记录。

## 模型调用

用户生成或修改计划时，客户端调用宿主能力 `model.complete`，把当次需要的目标、任务、时间块、工作时间、休息日与修改建议发送给宿主。宿主是否接入模型提供方、以及提供方如何处理这些资料，取决于用户自己在宿主中的配置；客户端不携带任何模型密钥。

宿主没有模型服务时，客户端自动进入演示模式，使用内置的固化数据完成全链路，不向任何模型发送数据。

## 数据边界

- 客户端清单只声明 `storage` 与 `model` 两项能力，不声明网络，也不请求任何网络主机。
- 客户端不读取设备时区文件，固定东八区。
- 初赛范围为单用户和单设备，项目使用应用内日历。
