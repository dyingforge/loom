# 正式提交所需资料

- 比赛对自建 Python 服务和 OctoScript 客户端的资格要求，需要由用户向赛事确认。
- 正式 OctoSense 宿主需要提供客户端使用的 `{{state}}` 业务存储服务和设备时区配置，并完成空白安装、保存核验及重新启动验证。
- 持续运行的公网 HTTPS 服务、发布者身份、支持联系方式和公开隐私说明入口，需要用户提供正式发布资料。
- 应用商店提交需要真实截图、最终应用包检查结果和审核问题回答。首次提交允许未签名；已有签名发布记录的后续提交需要使用登记密钥。

当前交付使用按 `native/LOCK.json` 构建的本地 card-host 和 Python 启动器。开发 HTTPS 连接要求保持本机服务与临时隧道运行。发布步骤及核查证据见 [AppHub 发布准备](APPHUB_PUBLISHING.md)。
