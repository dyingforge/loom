# 正式提交所需资料

- 比赛对自建 Python 服务和 OctoScript 客户端的资格要求，需要由用户向赛事确认。
- 提交期间需要保持本机服务与 Cloudflare 临时 HTTPS 隧道运行；隧道地址变化时需要同步更新应用与文档。
- 应用商店提交需要真实截图、最终应用包检查结果和审核问题回答。首次提交允许未签名；已有签名发布记录的后续提交需要使用登记密钥。

客户端按 `native/LOCK.json` 固定的官方 AppHub 提交构建，业务记录使用官方 `fs` 文件能力，时间固定为东八区（UTC+8）。提交使用本机服务与 Cloudflare 临时 HTTPS 隧道，需要保持服务与隧道运行。发布步骤及核查证据见 [AppHub 发布准备](APPHUB_PUBLISHING.md)。
