# 正式提交所需资料

- 比赛对零服务化 OctoScript 客户端的资格要求，需要由用户向赛事确认。
- 应用商店提交需要真实截图、最终应用包检查结果和审核问题回答。首次提交允许未签名；已有签名发布记录的后续提交需要使用登记密钥。当前 bundle 已包含执行闭环与真实模式能力补齐，提交前需要真机验证新功能并更新 `bundle/screenshots/01-main.png`。

客户端按 `native/LOCK.json` 固定的官方 AppHub 提交构建，业务记录使用官方 `fs` 文件能力，时间固定为东八区（UTC+8）。客户端零服务化，提交后不需要保持任何本机服务或隧道运行。发布步骤及核查证据见 [AppHub 发布准备](APPHUB_PUBLISHING.md)。
